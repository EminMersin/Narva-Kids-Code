# Narva Kids Code

Narva Kids Code, çocukların oyunlaştırılmış görevlerle kodlama ve algoritma mantığını öğrenebileceği bir eğitim uygulamasıdır.

## Chrome ile uygulama olarak yükleme

Uygulamayı [kids.narvaai.com](https://kids.narvaai.com/) adresinden açabilirsiniz.

**Android telefon veya tablette:**

1. Adresi Chrome ile açın.
2. Sağ üstteki üç nokta menüsüne dokunun.
3. **Uygulamayı yükle** veya **Ana ekrana ekle** seçeneğini seçin.
4. Kurulumu onaylayın. Narva Kids Code ana ekranda normal bir uygulama gibi açılacaktır.

**Bilgisayarda:** Chrome adres çubuğundaki yükleme simgesine tıklayın veya menüden **Narva Kids Code'u yükle** seçeneğini kullanın.

Uygulama ilk açılıştan sonra desteklenen içerikleri çevrimdışı kullanım için cihazda saklar.
